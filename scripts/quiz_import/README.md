# 問題集の取り込み

購入した問題集（PDF・Excel）を、ツールで読める CSV へ変換するスクリプトです。

## 流れ

```
購入問題/pdf/*.pdf   ─ pdf_to_csv.py  ─┐
                                        ├─→ 購入問題/csv/<問題集名>/*.csv ─→ ツールの「📂フォルダ読込」
購入問題/xlsx/*.xlsx ─ xlsx_to_csv.py ─┘              │
                                                      └─ check_csv.py ─→ _要確認リスト.csv
```

`購入問題/` は他者の著作物なのでリポジトリには入れません（`.gitignore` 済み）。

## 1. 変換する

```bash
python scripts/quiz_import/pdf_to_csv.py 購入問題/pdf/問題集.pdf
```

元ファイル1つにつき `購入問題/csv/<問題集名>/` を作り、その中へ CSV を書きます。
1ファイル 500 問で分割します（ツール側の1問題集あたりの上限に合わせています）。

ディレクトリを渡せばまとめて変換できます。Excel も同じ使い方です。

```bash
python scripts/quiz_import/pdf_to_csv.py 購入問題/pdf
python scripts/quiz_import/xlsx_to_csv.py 購入問題/xlsx
```

### うまく取れないとき

まず `--analyze` で、何をどう認識したかを見ます。CSV は書きません。

```bash
python scripts/quiz_import/pdf_to_csv.py --analyze 購入問題/pdf/問題集.pdf
```

列の境界・問題番号の位置・ルビの有無は自動で見つけますが、外したときは
上書きできます。よく使うもの:

| 指定 | 意味 | 効くとき |
| --- | --- | --- |
| `--x-split` | 問題文と答えの境界X | 答えの列を取り違えている |
| `--memo-x` | 備考列の左端X | 解説が答えに混ざる |
| `--q-min` | これより左は取り込まない | 作問者名が問題文に付く |
| `--num-range` | 問題番号の列のX範囲 | 問題の切れ目がずれる |
| `--anchor-source` | 問題番号の見つけ方 | 同上 |
| `--small` | 小さい文字の扱い（ルビ/備考/本文） | 読みが変な位置に入る |
| `--keep-all` | 疑問の形で終わらない行も残す | 体言止めの問題集で取りこぼす |

座標は `--analyze` の表示と、PDF ビューアの座標を見比べて決めます。

## 2. 点検する

```bash
python scripts/quiz_import/check_csv.py 購入問題/csv
```

怪しい行を `購入問題/csv/_要確認リスト.csv` に一覧します。
判定しているのは次の7つで、いずれも「怪しい」であって「間違い」ではありません。

| 理由 | 意味 |
| --- | --- |
| 列こぼれ | 答えが語頭にありえない文字で始まる。または助詞で始まり、かつ問題文が途中で切れている |
| こぼれ(メモ) | メモが同じ形で始まる（答えの末尾がメモへ流れた形） |
| 括弧の不一致 | 答えやメモで括弧の開きと閉じの数が合わない |
| 問題文途中 | 問題文が疑問の形で終わっていない |
| 問題混在 | 問題文の中に問いの終わりが2つ以上ある |
| 答えが長い | 括弧の中を除いた答えが40字を超える |
| 重複 | 同じ問題文が複数ある |

一覧を見ながら CSV を直すか、その行を消します。

## 3. ツールへ取り込む

「問題集管理」タブのフォルダ一覧にある 📂 ボタンで、`購入問題/csv/<問題集名>/`
を選びます。同じ名前のフォルダを作り、CSV ごとに問題集を作って入れます。

上限は 1問題集 500問 / 1フォルダ 50問題集・5000問です。

## 変換の仕組みを触るとき

判定を変えたら、回帰テストを通してください。PDF は使いません。

```bash
python scripts/quiz_import/test_quiz_import.py
```

過去に直した不具合（長い答えが備考へこぼれる、全幅の解説ページを表として読む、
問題文の後ろに次の問題の番号が付く、など）をそのまま残してあります。

## ファイル

| ファイル | 役割 |
| --- | --- |
| `pdf_to_csv.py` | PDF → CSV。列の境界やルビの扱いを自動で見つける |
| `xlsx_to_csv.py` | Excel → CSV |
| `check_csv.py` | 変換結果を点検して要確認リストを作る |
| `common.py` | 書き出しと整形の共通処理 |
| `test_quiz_import.py` | 判定の回帰テスト |
